
versiones:
 PHP 8.2     
 PostgreSQL 16   


requisitos:
Docker instalado
Puerto 8080 disponible.


pasos de instalación:


1. Clonar o descargar el proyecto en una carpeta local
2. Desde la carpeta raíz del proyecto ejecutar  'docker compose up --build'
3. Esperar que levante el docker y abrir el navegador en http://localhost:8080
4. Registrar un producto. El listado de bodegas, sucursales y monedas se  carga desde la base de datos.
